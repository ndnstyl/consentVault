Send your first test event

Use a test phone number you control. The event is real evidence in your ledger and cannot be deleted, so do not use a customer's number.

  1. Brand: Acme Lending Done
  2. Capture source: Website form Done
  3. Wording: Version 2026-10 Done
  4. Credential: Website form key Done

Send it

Server credential (get a token first) or site key (from your web form).

curl -X POST https://capture.consentvault.ai/v1/events \
  -H "Authorization: Bearer $TOKEN" -H "content-type: application/json" \
  -d '{"contact":"+15555550100","event_type":"grant","channels":["sms"],
       "purposes":["marketing"],"checked":true,"brand_ids":["brd_acme"],
       "disclosure_sha256":"9f2c...e1","source_id":"src_web"}'
Waiting for your first event from Website form. This box updates every 5 seconds for 15 minutes.
