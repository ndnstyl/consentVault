09. Credentials

Route: /credentials, /credentials/new · Roles: Admin (write); Developer (write, proposed)

Job: Issue, rotate and revoke the machine credentials that send events, check the gate, or read evidence.

Reads and writes: POST /v1/credentials, DELETE /v1/credentials/{id} (contracts/admin.md); scopes per contracts/auth.md. Gaps: GET list, issue response shape, private_key_refused and policy_required error names, last used time.

Low fidelity, grayscale. Spec of record: ../handoff.md. With scripts off, every state shows stacked.

State: Default
