12. Documentation checklists

Route: /checklists, /checklists/[version] · Roles: Admin (write); Compliance viewer and Developer (read)

Job: Let an admin define what each record should document, so every record shows which elements are present or missing.

Reads and writes: POST /v1/checklists, POST /v1/checklists/{version}:approve (contracts/admin.md). Gaps: GET list and one version, element schema, per-record results read.

Low fidelity, grayscale. Spec of record: ../handoff.md. With scripts off, every state shows stacked.
